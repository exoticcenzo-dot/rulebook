# THE RULE BOOK

Daily stickman series for @exoticcenzo. EXOTICCENZO teaches one lesson per episode; the story never ends.

- `series.json`: cast, voices and rules for writing scripts
- `scripts/epNNN.json`: one script per episode
- `show.py render N`: renders `out/epNNN.mp4`
- `setup.sh`: installs the voice model on a fresh machine
- `videos/`: finished episodes, pulled by Metricool
